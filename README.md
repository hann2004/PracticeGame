 🪨 Rock, 📄 Paper, ✂️ Scissors - Python Game

A simple terminal-based Rock, Paper, Scissors game built with Python. Play against the computer and see if you can win!

 How to Play

1. You'll be asked to enter your choice: Rock, Paper, or Scissor.
2. The computer randomly picks one too.
3. The winner is decided based on classic rules:
   - Rock beats Scissor
   - Scissor beats Paper
   - Paper beats Rock
4. You can keep playing as long as you want!

 What I Learned

- How to use Python functions
- Using conditionals (`if/elif/else`)
- Taking user input
- Using the `random` module
- Creating loops and handling invalid inputs

 How to Run It

Make sure you have Python installed.

Then run this in your terminal:

```bash
python game.py
